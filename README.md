## 2. Creative Direction & Design System

The visual language is inspired by premium creative agencies, high-end performance studios, and contemporary technology portfolios.

* **Primary Color (Deep Charcoal):** `#151515` — establishes depth, gravitas, and modern focus.
* **Secondary Color (Warm Off-White):** `#F7F6F2` — delivers warm, editorial high contrast without blinding starkness.
* **Accent Color (Electric Lime):** `#C6F36A` — selectively applied to conversion triggers, active states, badges, and ROI metrics.
* **Supporting Neutral (Muted Grey):** `#888888` / `#AAAAAA` — clean metadata and secondary copy.
* **Typography Hierarchy:**
  * **Headings:** *Syne* (800 / 700 Extra Bold) — oversized, confident editorial display.
  * **Body:** *Plus Jakarta Sans* (400 / 500 / 600) — highly readable, modern geometric sans-serif.
  * **Metrics & Metadata:** *JetBrains Mono* — data precision and technical grounding.

## 5. Local Setup & Deployment

### Run Locally:
Simply open `index.html` directly in any modern browser, or run a local static server:
```bash
# Using Python
python -m http.server 3000

# Or using Node / npx
npx serve .
```

### Deploy to Vercel:
```bash
# Deploy with Vercel CLI
vercel --prod
```
The included `vercel.json` automatically configures clean URLs, asset caching headers, and security protections.
